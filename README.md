# ReFinder
## Aplicação Android de perdidos e achados
Permite aos utilizadores registar um objeto encontrado, juntamente com os seus detalhes, de modo a encontrar o seu dono original.

### Funcionalidades principais:
- Adicionar um objeto:
    - Perdido
    - Achado
- Associar uma descrição, foto, data e localização ao objeto achado e posibilidade de o guardar num cacifo dedicado
- Pesquisa por filtros (tamanho, cor, localização)
- Navegação assistida até ao cacifo e utilização de *QR codes* para o desbloquear de forma segura
- Criação de conta para maior fiabilidade
